# منصة المهارات الرقمية

واجهة تدريب عربية مبنية بـ React وVite، مع 10 وحدات تعليمية، مختبر تفاعلي، تقييم شامل من 30 سؤالًا، وتسجيل دخول محلي يحفظ تقدم كل متدرب ونتيجته.

## التشغيل

المتطلبات: Node.js 22 أو أحدث، وPython 3، ومكتبة Flask.

```bash
npm ci
python3 -m pip install -r requirements.txt
npm run dev
```

يفتح Vite الواجهة على `http://localhost:5173`. يبدأ أمر التطوير خادم Flask وقاعدة SQLite تلقائيًا؛ لا تشغّل الواجهة وحدها إذا أردت استخدام التسجيل وحفظ التقدم.

## الحساب والتقدم

إنشاء الحساب/تسجيل الدخول محليان لهذا التطبيق. كلمات المرور تُخزّن باستخدام PBKDF2، والجلسات في ملف تعريف ارتباط `HttpOnly`، والتقدم ونتائج التقييم في قاعدة SQLite (`data/learning.sqlite3`). قاعدة البيانات مستثناة من Git ولا تُرفع إلى المستودع.

هذا إعداد تطوير/عرض يعمل على خادم المشروع الحالي؛ لا تعتبره خدمة استضافة إنتاجية متعددة الأجهزة. قبل النشر العام، انقل قاعدة البيانات إلى مخزن دائم محمي، فعّل HTTPS وإدارة الأسرار والنسخ الاحتياطية وحدود محاولات الدخول، أو اربط مزود مصادقة مُدارًا.
